# Изменения

## 1.0.1 — 2026-11-19
- `tests/install-dryrun.sh` больше не зависит от машины, на которой его запускают: заглушки `ss` и `ip`,
  путь к TUN — через `CB_TEST_TUN_DEV` (только для тестов; `install.sh` предупреждает, если она задана).
  Раньше в контейнере агента обычная установка падала, а проверка конфликта проходила вхолостую.
- `run-all.sh`: проверка предупреждения о `CB_TEST_TUN_DEV`.
- `__pycache__` убран из репозитория и добавлен в `.gitignore`.

## 1.0.0 — 2026-11-19
Единый репозиторий вместо двух пакетов (`claude-box-mac` и облегчённого `server/`).

- **Один `install.sh`** для Mac и Linux: профили `mac`/`server` (только умолчания), флаги `--browser`,
  `--docker ro|0`, `--host-access`, `--yes`, `--force`; `--check` (проверка системы без изменений),
  `--update [--detach]`, `--report` (диагностика с замаскированными паролями), журнал `install.log`.
- **Проверка системы**: ОС и архитектура, виртуализация (OpenVZ/LXC), `/dev/net/tun`, версии Docker и compose,
  RAM и диск (минимумы с браузером и без), занятые порты, чужие контейнеры с теми же именами, пересечение
  подсетей с сетями Docker и маршрутами хоста, sshd/«Удалённый вход», доступность прокси.
- **docker-ro** `[security]`: Docker API хоста только для чтения (свой фильтр: GET по белому списку, без
  archive/export/exec, один запрос на соединение). Агент смотрит `docker ps/logs/inspect/stats` без
  подтверждений; изменения — `ssh host 'docker …'` с подтверждением.
- **host-guard** `[security]`: подтверждение для любого SSH (не только к Mac) и для обращений к хосту;
  `docker run/compose up/...` через CLI контейнера — отказ с подсказкой; прямые SSH-цели в локальной сети —
  отказ; скрипты и tmux-обёртки с SSH — подтверждение. Managed-правила `ask`: `ssh`, `scp`, `sftp`, `rsync *:*`.
- **Правила агента под профиль**: `/etc/claude-code/CLAUDE.md` собирается при старте из частей
  (`agent/claude/md/`): Mac, сервер, без доступа к хосту, браузер, Docker.
- **SSH_HOSTS** в `.env`: алиасы других серверов для агента (`vds=root@ip:22`), с подтверждением.
- Имена контейнеров и проекта из `.env` (`BOX_PREFIX`, `COMPOSE_PROJECT_NAME`, `BOX_HOSTNAME`), чтобы ставить
  рядом с чужими контейнерами; `PUID=0` запрещён; установка внутри рабочей папки агента запрещена.
- `host-firewall.sh`: трафик внутри подсети claude-box (шлюз ↔ docker-ro) не режется; юнит ставит install.sh
  с реальным путём.
- `tests/`: проверки без Docker (`bash tests/run-all.sh`).
- Сценарий для агента: `prompts/INSTALL_VDS.md` (установка на сервер).
