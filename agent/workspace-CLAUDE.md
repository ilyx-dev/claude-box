# Мои проекты

Общие правила для всех чатов. Этот файл лежит в `/workspace` (на Mac — `~/claude-workspace`).
Все чаты Remote Control начинаются в `/workspace`, поэтому видят его сразу. Правь под себя.

## Структура
- Каждый проект — отдельная папка: `/workspace/<имя-проекта>`.
  Имя — латиница в нижнем регистре, цифры, дефис (`site`, `telegram-bot`, `price-parser`).
- Служебные папки начинаются с `_`, проектами не считаются:
  - `/workspace/_reports` — отчёты;
  - `/workspace/_tmp` — временные файлы;
  - `/workspace/_worktrees` — параллельные копии проектов (см. ниже).
- `/workspace/downloads` — загрузки браузера агента.

## С каким проектом работаем
- В начале чата я называю проект («проект site: …»). Если не назвал, а задача касается
  конкретного проекта, — **спроси**, не угадывай. Вопросы «обо всём» (список проектов, Mac,
  общие скрипты) — без проекта.
- Определив проект, **первым делом прочитай `/workspace/<проект>/CLAUDE.md`** (и README.md),
  затем работай из папки проекта: `cd /workspace/<проект>` в начале каждой Bash-команды.
- Работай только в папке текущего проекта. В соседние проекты не заходи и ничего там не меняй,
  если я прямо не попрошу.
- Кратко назови проект в первой строке ответа: так в списке чатов видно, что где.

## Параллельная работа над одним проектом
Если я пишу «параллельно» или ты знаешь, что этот проект сейчас правится в другом чате,
работай в отдельной копии:
`git -C /workspace/<проект> worktree add /workspace/_worktrees/<проект>-<задача> -b <задача>`.
Работай там, а по окончании предложи слить ветку в основную и удалить worktree.

## Правила работы
- В каждом проекте должны быть:
  - `CLAUDE.md` — описание, стек, как запускать и тестировать, договорённости;
  - `README.md` — для людей;
  - git-репозиторий; коммиты небольшие, сообщения на русском.
- Секреты (токены, пароли, ключи API) — только в `.env` проекта, `.env` всегда в `.gitignore`.
- Узнал о проекте что-то важное (как запускать, подводные камни) — допиши в его `CLAUDE.md`.

## Новый проект
Когда я прошу начать новый проект, выполни `new-project <имя> "<краткое описание>"`.
Команда создаёт папку, git, `CLAUDE.md`, `README.md`, `.gitignore` и добавляет проект в список ниже.
