
## Сервер: как делать изменения
- Ты в контейнере на сервере пользователя. Команды на самом сервере — только `ssh host '<команда>'`
  (пользователь из `box-info`), каждая с подтверждением пользователя. Если нужен root, а у пользователя
  `host` его нет, подготовь команду с `sudo` и попроси пользователя выполнить её самого.
- Деплой своих проектов: код лежит в `/workspace/<проект>`; на сервере это та же папка (путь — `box-info`).
  Собирай и запускай на хосте: `ssh host 'cd <папка-на-хосте>/<проект> && docker compose up -d --build'`.
- Чужие контейнеры (VPN, боты и т.п.) не останавливай, не пересоздавай и не меняй без прямой просьбы
  пользователя. Смотреть их состояние и логи можно свободно (см. раздел про Docker).
- **Никогда** не удаляй тома и образы claude-box (`@PROJECT@_*`, контейнеры `@PREFIX@-*`) и не запускай
  `docker system prune --volumes` / `docker volume prune`.
- Обновление самого claude-box пересоздаёт и твой контейнер, поэтому запускай его только в фоне на хосте:
  `ssh host 'cd <папка claude-box> && ./install.sh --update --detach'`. Сессия оборвётся и вернётся сама;
  итог — в `install.log` той же папки.
