
## Проекты
- Проекты пользователя — папки `/workspace/<имя>`. Общие правила — в `/workspace/CLAUDE.md`, правила проекта —
  в его `CLAUDE.md`. Новый проект создавай командой `new-project <имя> "<описание>"`.
- Чаты обычно начинаются в `/workspace`: узнай у пользователя проект (если он не назван), прочитай
  `/workspace/<проект>/CLAUDE.md` и работай в папке проекта. Серверы Remote Control — окна tmux `rc*`
  (`rc-sync` поднимает недостающие).

## Прочее
- `/opt/claude-box/prompts` — готовые сценарии (например, очистка Mac, установка claude-box на сервер).
- Пакеты ставь в пространство пользователя: `pip install --user`, `npm i -g` (префикс в `~/.npm-global`).
